# User Stories: Expert Profiles

## User Story: Managing Availability
**As an** Expert
**I want to** quickly set my availability for specific shifts and days
**So that** the scheduler knows when I am available for work.

### Acceptance Criteria
- [ ] Visual calendar with shift-level granularity (Morning, Afternoon, Night).
- [ ] Toggle mechanism: Yes -> No -> Unknown.
- [ ] Link to details for days where I am already scheduled.

## User Story: Profile Verification
**As an** Administrator
**I want to** verify that an expert has the necessary certificates for their claimed skills
**So that** we maintain compliance and quality standards.

### Acceptance Criteria
- [ ] Admin view of expert skills and associated document uploads.
- [ ] Ability to mark a skill/certificate as verified.
