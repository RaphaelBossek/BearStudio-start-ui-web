# User Stories: Consultation Scheduling

## User Story: Recurring Schedule Creation
**As a** Staff Member
**I want to** define a recurring weekly or monthly consultation schedule for an expert
**So that** I don't have to manually create every single appointment slot.

### Acceptance Criteria
- [ ] Ability to select recurrence: Weekly, 1st of month, X-th day of month, Specific day, or Last day.
- [ ] Option to set an end date or a fixed number of recurrences.
- [ ] Preview of generated dates before saving.

## User Story: Schedule Conflict Detection
**As a** Scheduler
**I want to** be notified if an expert is already assigned to another service at the same time
**So that** I avoid double-booking and maintain a reliable schedule.

### Acceptance Criteria
- [ ] Immediate feedback when overlapping slots are detected for the same expert.
- [ ] Warning if the assigned location is already in use.
